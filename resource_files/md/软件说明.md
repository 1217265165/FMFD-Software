# FMFD软件说明文档

## 软件简介

FMFD (Frequency Measurement and Fault Diagnosis) 是一个基于Qt的频率测量与故障诊断系统，用于仪器控制、数据采集和智能诊断。

---

## 项目结构

### 主程序文件
- **main.cpp** - 程序入口，创建主窗口
- **FMFD.h / FMFD.cpp** - 主窗口类，负责UI布局和事件处理

### 配置对话框模块
- **FrequencySweepConfigDialog.h/cpp** - 频率扫描配置对话框
- **SpectrumAnalyzerConfigDialog.h/cpp** - 频谱分析仪配置对话框
- **SignalGeneratorConfigDialog.h/cpp** - 信号发生器配置对话框
- **SchemeManagementDialog.h/cpp** - 方案管理对话框

### UI辅助模块
- **UsageDialog.h/cpp** - 使用说明对话框
- **ZoomableGraphicsView.h/cpp** - 可缩放的图形视图组件

### 业务逻辑模块
- **DataAcquisitionService.h/cpp** - 数据采集服务
- **InstrumentController.h/cpp** - 仪器控制器（VISA通信）
- **SchemeManager.h/cpp** - 测试方案管理器
- **brbengine.h/cpp** - BRB（Belief Rule Base）诊断引擎

### 公共定义
- **CommonTypes.h** - 公共类型定义（结构体、枚举等）

### 其他文件
- **FMFD.ui** - Qt Designer UI文件（未使用，可删除）
- **VISA_TCPIP_参考指南.md** - VISA TCPIP通信参考文档

## 功能模块说明

### 1. 数据采集模块

**功能：**
- 自动化频率响应测试
- 支持分段扫描和文件导入两种模式
- 实时数据采集和处理

**主要类：**
- `DataAcquisitionService` - 数据采集服务
- `InstrumentController` - 仪器控制接口

**配置选项：**
- 频率范围和步进
- 功率设置
- RBW（分辨率带宽）
- VBW（视频带宽）

### 2. 仪器控制模块

**功能：**
- VISA协议仪器通信
- 信号发生器控制
- 频谱分析仪控制

**支持的仪器：**
- 信号发生器（SG）
- 频谱分析仪（SA）

**通信方式：**
- TCPIP Socket连接
- 标准SCPI命令

### 3. 方案管理模块

**功能：**
- 测试方案的保存和加载
- 方案参数配置
- 方案列表管理

**包含配置：**
- 频率扫描配置
- 频谱分析仪参数
- 信号发生器参数

### 4. BRB诊断引擎

**功能：**
- 基于信念规则库的智能故障诊断
- 多模块故障概率推理
- 系统级和模块级诊断结果

**诊断特征：**
- 幅度误差（AmplitudeErr）
- 频率误差（FrequencyErr）
- 参考电平偏移（RefLevelOffset）

**诊断模块：**
- RF前端模块（衰减器、前置放大器、滤波器、混频器等）
- 时钟系统（振荡器、合成器）
- 本振系统
- 校准系统
- 数字处理（ADC、FPGA）
- 电源模块

### 5. 可视化模块

**功能：**
- 系统结构图显示
- 故障症状可视化
- Python集成可视化工具

**可视化类型：**
- 主结构图
- 频率精度异常
- 幅度测量不准确
- 参考电平失准

## 系统要求

### 开发环境
- Visual Studio 2017 或更高版本
- Qt 5.12 或更高版本
- C++11 或更高标准

### 运行环境
- Windows 10 或更高版本
- .NET Framework（根据Qt版本要求）

### 硬件要求
- 支持VISA协议的测试仪器
- 网络连接（用于TCPIP通信）

## 代码组织特点

### 模块化设计
- 各功能模块独立成文件
- 清晰的接口定义
- 低耦合高内聚

### 配置管理
- 统一的配置结构体
- 配置的保存和加载
- 用户友好的配置界面

### 数据流程
1. UI配置 → 参数设置
2. 参数验证 → 仪器初始化
3. 数据采集 → 实时处理
4. 特征提取 → 故障诊断
5. 结果显示 → 可视化展示

## 使用建议

### 开发建议
1. 遵循现有的模块划分原则
2. 新增功能时考虑创建独立模块
3. 保持代码风格一致
4. 添加必要的注释和文档

### 维护建议
1. 定期检查未使用的文件
2. 及时更新文档
3. 保持依赖关系清晰
4. 进行代码审查

### 扩展建议
可以进一步拆分的模块：
- BRB诊断管理器（~200行）
- Python可视化管理器（~150行）
- UI事件处理器（~100行）
