## 规则激活流程对比

### 传统单层BRB

```
全部特征 (8-15维)
        │
        ▼
   全部规则 (60-130条)
   ┌─────┬─────┬─────┬─────┐
   │ R1  │ R2  │ ... │ R130│  ← 全部激活
   └─────┴─────┴─────┴─────┘
        │
        ▼
   模块故障概率
```

### 本文分层BRB

```
全局特征 (4维)                 细粒度特征 (3维)
     │                              │
     ▼                              │
系统级规则 (12条)                   │
┌────┬────┬────┬────┐              │
│ R1 │ R2 │... │ R12│               │
└────┴────┴────┴────┘              │
     │                              │
     ▼ 确定主导类型                 │
     │                              │
     ├─ 幅度失准 ───────────────────┼─▶ 规则子库A (11条)
     │                              │   ┌────┬────┬────┐
     ├─ 频率失准 ───────────────────┼─▶ │ R1 │... │ R11│
     │                              │   └────┴────┴────┘
     └─ 参考电平失准 ───────────────┼─▶ 规则子库C (11条)
                                    │
                                    ▼
                             模块故障概率

总激活规则: 12 + 11 = 23条 (vs 60-130条)
```

## 证据推理合成过程

```
规则 k=1:
β₁ = {D₁: 0.75, D₂: 0.10, D₃: 0.10, Normal: 0.05}
w̃₁ = 0.3
                ↓
            合成 (公式2-6, 2-7)
                ↓
规则 k=2:
β₂ = {D₁: 0.82, D₂: 0.08, D₃: 0.07, Normal: 0.03}
w̃₂ = 0.25
                ↓
            合成
                ↓
              ...
                ↓
            合成
                ↓

β₁₂ = {D₁: 0.35, D₂: 0.30, D₃: 0.25, Normal: 0.10}

                ↓
```

## 反馈修正机制

```
         诊断预测
             │
             ▼
        检修验证
             │
             ├─── 预测正确 ───▶ 增加相关规则权重 (+Δw)
             │                  w'ₖ = wₖ + α(1-wₖ)
             │
             └─── 预测错误 ───▶ 减少相关规则权重 (-Δw)
                                w'ₖ = wₖ - α·wₖ
             
             其中 α = 学习率 (默认0.1)
```
